# 🛡️ Professional Phishing Awareness Training Portal

A comprehensive cybersecurity awareness platform built with **Python** and **Streamlit** that educates users on phishing attacks through interactive learning modules, phishing email analysis, fake website detection, social engineering awareness, real-world attack scenarios, quizzes, analytics, and certificate generation.

This project is designed to help students, employees, and organizations improve their ability to recognize and defend against phishing attacks using an engaging, hands-on training experience.



## ✨ Key Features

- 📧 Phishing Email Analysis
- 🌐 URL Risk Analyzer
- 🎭 Social Engineering Awareness
- 🕵️ Fake Website Detection
- 📚 Interactive Learning Modules
- 🌍 Real-World Phishing Case Studies
- 📊 Progress Tracking & Analytics
- 📝 Interactive Knowledge Quiz
- 🏆 Certificate Generation
- 🎨 Modern Streamlit Interface



## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- Matplotlib
- Pillow



## 🚀 Getting Started

```bash
git clone https://github.com/yourusername/Professional-Phishing-Awareness-Training-Portal.git

cd Professional-Phishing-Awareness-Training-Portal

python3 -m venv .venv

source .venv/bin/activate

pip install -r requirements.txt

streamlit run phishing_training.py
```



## 🎯 Learning Outcomes

After completing the training, users will be able to:

- Identify phishing emails
- Detect malicious URLs
- Recognize fake websites
- Understand social engineering tactics
- Apply cybersecurity best practices
- Respond effectively to phishing incidents
